Web Flasher

Install the PocketHID firmware and built-in PWA on any ESP32-S3 over USB via ESP Web Tools. No local toolchain needed.

Install on ESP32-S3

Connect your board with a USB-C data cable and start flashing from Chrome or Edge.

Web Serial is not supported in this browser.
Use desktop Chrome or Edge (Windows, Linux, macOS). Safari and mobile browsers are not supported — for updates use WiFi OTA at http://pockethid.local/update.
HTTPS and serial access required. Serve this page over HTTPS and allow serial port permissions.
ESP32-S3 ≥ 4 MB Flash USB-C Data Cable Firmware + LittleFS PWA

1 Flash over USB

  1. Connect your ESP32-S3 via USB-C. On dual-USB boards use the UART port; on single-USB boards use the only USB-C port.
  2. Click Install PocketHID and select the serial port (USB Serial/JTAG, CP210x, or CH340).
  3. If flashing does not start on a single-USB board: unplug USB, hold BOOT, plug USB back in, release after ~2s, then retry.
Single-USB boards: after flashing finishes, unplug and replug the USB cable without holding BOOT to start the firmware.

2 Connect & control

  1. Plug the ESP32-S3's USB-OTG port into your target TV, PC, or tablet.
  2. Bluetooth (no WiFi needed): switch to or use the Android APK, then pair with PocketHID.
  3. WiFi / built-in PWA: join PocketHID-XXXX (password pockethid1), open http://192.168.4.1/portal to save your home WiFi, and after reboot open http://pockethid.local/.
Need custom key sequences? Build or record them in and push directly over BLE.
Future firmware updates can be uploaded over WiFi at http://pockethid.local/update. Android APK & Releases →
