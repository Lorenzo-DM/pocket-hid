PocketHID · Web Flasher

One-click USB installation for ESP32-S3 with ESP Web Tools (flashes both the firmware and the built-in PWA — no tools to install). · Open Web App (HTTPS / BLE) → · Macro Studio →

Web Serial is not supported by this browser.

Use desktop Chrome or Edge (Windows, Linux, macOS). Safari and iOS are not supported — for future updates you can use WiFi OTA (http://pockethid.local/update).

This page must be served over HTTPS and serial access must be allowed.

1. Flash the ESP32-S3

  1. Connect your ESP32-S3 via USB-C. On dual-USB boards use the UART port; on single-USB boards (direct OTG) use the only USB-C port.
  2. Click Install PocketHID and select the serial port (e.g. USB Serial/JTAG or CP210x/CH340).
  3. If flashing doesn't start automatically on a single-USB board: unplug USB, hold BOOT, plug USB back in, release BOOT after ~2s, then retry.
  4. After flashing (single-USB boards): unplug and replug the USB cable without holding BOOT to start the firmware.

2. First-time setup

  1. Plug the ESP32-S3's USB-OTG port into your target TV or PC.
  2. Bluetooth (no WiFi needed): open the hosted HTTPS Web App (installable as a PWA in Chrome/Edge) or the Android APK, and pair with PocketHID.
  3. WiFi / built-in PWA: connect your phone to the WiFi hotspot PocketHID-XXXX (default password: pockethid1), open http://192.168.4.1/portal to enter your home WiFi credentials, and after reboot open http://pockethid.local/.

Compatible with any ESP32-S3 board with ≥ 4 MB flash. Subsequent updates can be uploaded over WiFi at http://pockethid.local/update.
