MK-Remote · flash firmware

Installazione via USB con ESP Web Tools (esptool-js, tutto in browser — nessun programma da installare).

⚠ Web Serial non supportato da questo browser.

Usa Chrome o Edge su desktop (Windows/Linux/macOS). Safari e iOS non sono supportati — da iPhone/iPad usa la OTA via WiFi (http://<ip-esp>/update) o collega l'ESP a un computer con Chrome.

⚠ Questa pagina non è servita in HTTPS o non hai concesso l'accesso: Web Serial funziona solo su pagine sicure.

Procedura per la board single-USB

  1. Collega la board via USB-C (unico connettore, direct OTG).
  2. Premi ⚡ Installa firmware e scegli la porta USB Serial/JTAG.
  3. Se il browser non entra da solo in download mode: tieni premuto BOOT mentre ricolleghi il cavo, poi riprova.
  4. Dopo il flash: la ROM resta in download mode — stacca e riattacca il cavo per avviare l'app (il reset via USB-Serial-JTAG non basta).
  5. Prima installazione: configura il WiFi dal captive portal — connettiti all'AP MK-Remote-XXXX (password nel file config.h del repo).

Porte: UART vs OTG

Sulle board con due porte: usa la UART per flash/log e la OTG per l'HID verso il target. Su questa board single-USB la stessa porta fa tutto: HID quando l'app gira, seriale in download mode.

Alternativa sempre valida: PlatformIO (pio run -t upload) oppure OTA WiFi (/update sull'ESP) per gli aggiornamenti successivi.
